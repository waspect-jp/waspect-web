# Waspect (和スペクト)

Marketing website for [Waspect](https://waspect.jp) — AI literacy education for schools, businesses, and families in Japan.

## Stack

- [Astro](https://astro.build) + [Tailwind CSS](https://tailwindcss.com)
- Japanese (default) + English via i18n
- Hosted on [Netlify](https://netlify.com)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
